# Центр воркеров XEDOC

Локальное приложение для Windows на Python 3 (без дополнительных пакетов).

Запуск: `powershell -NoProfile -ExecutionPolicy Bypass -File .\worker-center\launch.ps1`.
Адрес: http://127.0.0.1:8787. Ярлык создаётся `worker-center/install-shortcut.ps1`.
После перезагрузки ПК откройте ярлык: он поднимет центр и откроет страницу.
Повторный запуск ярлыка использует существующий центр. Закрытие вкладки оставляет
центр и воркеры работающими. Автозагрузка Windows не изменяется.

Каталог в `server.py`: YuE2, ComfyUI, Model Studio, Kimodo, Ollama, GPT-OSS,
ChatGPT Gateway, GigaEmbeddings, Open WebUI. Это настроенный список сервисов
данного компьютера, не автоматическое обнаружение всех программ Windows.
Чтобы подключить ещё один сервис, добавьте запись в `catalog()` и перезапустите центр.

Статус проверяется каждые 5 секунд по локальным health API, процессам и задачам
Windows. У YuE2 нет health API: «Работает» подтверждает процесс, но не связь с
серверной очередью; активный CLI отмечается отдельно. Занятость GPU сама по себе
не считается доказательством генерации. Конфигурация YuE2 читается только для
проверки наличия файлов и обязательных настроек; токен не возвращается в браузер.

Запуск доступен для остановленных настроенных сервисов. Команда выполняется
в фоне без консоли, повторный запуск блокируется, готовность подтверждается
следующей проверкой. Общие запускаторы Studio/RAG могут запускать зависимые
движки — это указано в карточках. GPU-модели не запускаются при открытии центра.
Сервисы с процессом без health-ответа требуют диагностики; центр не убивает их.

Журналы центра: `%LOCALAPPDATA%\XEDOCWorkerCenter`. В журнал карточки попадают
вывод запускатора и последние 12 КБ известных сервисных логов. Для старой задачи
YuE2 доступен результат команды запуска, но не stdout давно запущенного воркера.

Сервер слушает только `127.0.0.1`, проверяет Host и Origin, требует секрет сессии
в заголовке при запуске. API принимает только фиксированные ID из каталога,
не команды, пути или имена произвольных задач. CORS не включён.

Проверки: `python -m unittest discover -s worker-center -p "test_*.py"`.
